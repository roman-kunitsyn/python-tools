# voice-note Playback Fallback for Text-Only Notes

## Summary

Added a macOS text-to-speech fallback so pressing `p` on a note without source
audio now speaks the note text with `say`.

## Changes

- Added `speak_text()` in `voice_note.audio.player`.
- Kept the existing recorded-audio playback path intact.
- Updated the TUI `p` action to choose audio playback when an audio file exists
  and `say` when it does not.
- Added tests for the macOS `say` command path and the TUI fallback branch.

## Checks Run

- `PYTHONPATH=src/voice-note uv run python -m unittest discover -s src/voice-note/tests`

## Notes

- The fallback is intentionally macOS-only because the request specified the
  built-in `say` command.
