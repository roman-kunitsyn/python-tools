# voice-note Ollama Client and Assistant Generation

## Summary

Added the Ollama client and assistant generation service so assistant prompts
can be sent with session-note context and the response can be stored back into
assistant artifacts.

## Changes

- Added `OllamaClient` for `/api/chat` requests using the official Ollama chat
  message format.
- Added `OllamaChatResult` to normalize the returned response payload.
- Added `AssistantService` to combine session notes, context building, Ollama
  requests, and assistant message persistence.
- Kept the Ollama client isolated from the TUI so it can be tested with a fake
  HTTP client.
- Added tests for request construction, response parsing, error propagation,
  and assistant generation flow.

## Checks Run

- `PYTHONPATH=src/voice-note uv run python -m unittest discover -s src/voice-note/tests`

## Notes

- This slice uses non-streaming chat responses first. The client shape keeps the
  streaming flag in place so later TUI streaming support can build on the same
  interface.
