# voice-note Structured Note Storage Report

## Summary

Added a structured note store so `notes.json` is the source of truth and `transcribe.txt` is regenerated from it after each note update.

## Changes

- Added `SessionNote` as a structured note model with id, text, timestamp, and audio reference.
- Added `SessionNoteStore` to append notes, load existing notes, and rewrite both `notes.json` and `transcribe.txt`.
- Switched the default structured session artifact from `transcribe.json` to `notes.json`.
- Updated `VoiceNoteService` to persist through the session store when available.
- Kept CLI output behavior by using stdout for CLI mode and a null writer for TUI mode.
- Updated the TUI startup flow to load existing notes from the session store and render newest-first.
- Added tests for note ordering, transcript regeneration, and service/store integration.
