# voice-note Notes Tab Simplification

## Summary

Removed the note detail and action block from the Notes tab so the transcript panel can use that space.

## Changes

- Kept the Notes tab focused on the transcript list only.
- Removed the selected-note detail card from the Notes tab layout.
- Left note actions available through the existing keyboard bindings and code paths.

## Checks Run

- `UV_CACHE_DIR=/tmp/uv-cache PYTHONPATH=src/voice-note uv run python -m compileall src/voice-note/voice_note/tui/app.py`
- `UV_CACHE_DIR=/tmp/uv-cache PYTHONPATH=src/voice-note uv run python -m unittest discover -s src/voice-note/tests`

## Notes

- This makes the transcript the primary visible element in the Notes tab.
- If you want the note actions back, they can be moved to the Session tab or into a slim toolbar instead of a large detail pane.
