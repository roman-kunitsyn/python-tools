# voice-note Assistant Storage and Prompt Context

## Summary

Added the first assistant backend slice: a structured assistant message model,
an assistant message store, and a context builder that turns session notes into
Ollama-ready chat context.

## Changes

- Added `AssistantMessage` as a first-class model for assistant turns.
- Added `AssistantMessageStore` with JSON and human-readable text artifacts in
  the session folder.
- Added `AssistantContextBuilder` to assemble a system prompt plus user prompt
  from the current session notes.
- Added assistant artifact paths to the session model and session initialization
  flow.
- Added tests that cover assistant message persistence, transcript rendering,
  and note-context assembly.

## Checks Run

- `PYTHONPATH=src/voice-note uv run python -m unittest discover -s src/voice-note/tests`

## Notes

- This slice intentionally stops before the Ollama HTTP client and the TUI chat
  workspace. It gives those later tasks a stable storage and context layer
  without affecting the Notes tab.
