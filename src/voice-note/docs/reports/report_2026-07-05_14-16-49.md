# Report: Assistant prompt audio retention and replay

## Goal
Keep the original recorded audio for Assistant prompts so selected prompts can be replayed from the Assistant tab.

## What changed
- Assistant voice prompts now preserve their source audio path when the recording is transcribed.
- Assistant message records store `source_audio` in `assistant.json` and render an `[audio]` marker in the UI.
- Playing a selected Assistant prompt now replays the original recording if it exists; otherwise it falls back to text-to-speech.
- Notes behavior was left unchanged.

## Files touched
- `voice_note/tui/app.py`
- `voice_note/services/assistant_service.py`
- `voice_note/tests/test_voice_note_service.py`
- `voice_note/docs/IMPLEMENTATION_PLAN.md`

## Verification
- Test suite passed: `41 tests OK`

## Notes
- Assistant prompt recordings are kept through the existing TUI audio retention path, so no extra copy step was needed.
- This change only affects Assistant messages with `role == "user"` and a stored `source_audio` path.
