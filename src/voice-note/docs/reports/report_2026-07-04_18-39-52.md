# voice-note Main Workspace Slice Report

## Summary

Reworked the TUI main workspace to support a selectable transcript table, session QR panel, note detail panel, zoom controls, and audio playback.

## Changes

- Added a `DataTable`-based transcript view so notes are scrollable and newest-first.
- Added a session summary strip with a session-folder link and a QR code panel.
- Added a note detail panel that follows the highlighted row.
- Added playback support for notes that have source audio.
- Added zoom in/out controls for transcript density.
- Added full-screen recording styling and a blinking status bar treatment.
- Installed the `qrcode` dependency so the QR panel can render a real QR code when the package is available.
- Added an audio playback helper that prefers `afplay` on macOS and `ffplay` elsewhere.
