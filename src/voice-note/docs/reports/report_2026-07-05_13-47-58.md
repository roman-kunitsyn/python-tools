# voice-note Shared Workspace Component Refactor

## Summary

Extracted the reusable note rendering and Assistant placeholder workspace into
separate TUI modules so `voice_note/tui/app.py` is thinner and easier to extend
without duplicating Notes behavior.

## Changes

- Moved note card rendering into `voice_note/tui/components.py`.
- Moved the scrollable note transcript view into `voice_note/tui/views.py`.
- Moved the Assistant placeholder tab into `voice_note/tui/assistant.py`.
- Updated `voice_note/tui/app.py` to use the extracted modules instead of
  defining the note view inline.
- Added tests for the extracted note card renderer and Assistant tab builder.
- Kept Notes behavior unchanged while moving the shared rendering code out of
  the app shell.

## Checks Run

- `PYTHONPATH=src/voice-note uv run python -m unittest discover -s src/voice-note/tests`

## Notes

- This refactor is a setup step for the real Assistant workflow. It gives the
  chat UI a separate home without changing the already-stable Notes tab.
