# voice-note Startup Modal Regression Fix

## Summary

Fixed the TUI startup crash caused by using `push_screen_wait` from `on_mount`.

## Changes

- Replaced `push_screen_wait` with callback-based `push_screen` in the TUI app startup flow.
- Kept the session chooser modal, but now it dismisses through a normal screen callback.
- Simplified the session activation path so selected sessions are handled synchronously.

## Checks Run

- `python -m compileall src/voice-note/voice_note src/voice-note/tests`
- `PYTHONPATH=src/voice-note uv run python -m unittest discover -s src/voice-note/tests`

## Notes

- The session-first TUI flow now starts without the Textual `NoActiveWorker` error.
