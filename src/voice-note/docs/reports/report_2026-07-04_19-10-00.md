# voice-note TUI Audio Retention Fix

## Summary

Fixed the TUI runtime so recorded audio files are kept in the session folder instead of being cleaned up immediately.

## Changes

- Made TUI sessions preserve audio by forcing `keep_audio=True` in the TUI runtime builder.
- Tightened transcript table initialization so note rows are populated consistently.

## Checks Run

- `python -m compileall src/voice-note/voice_note src/voice-note/tests`
- `PYTHONPATH=src/voice-note uv run python -m unittest discover -s src/voice-note/tests`

## Notes

- This addresses the missing WAV files in session folders.
- The note table and detail pane should now reflect saved notes after recording or manual edits.
