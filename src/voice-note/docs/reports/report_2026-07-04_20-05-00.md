# voice-note TUI Tabbed Main Screen

## Summary

Added a tabbed main screen so the TUI now separates notes, session info, help, and settings into distinct panels.

## Changes

- Added a top tab bar with `Notes`, `Session`, `Help`, and `Settings`.
- Kept the notes workflow in its own tab with transcript and note details/actions.
- Moved session metadata, folder link, QR code, and session folder action into a dedicated session tab.
- Added a help tab with a short app overview.
- Added a settings tab that summarizes input and output sources from the current runtime settings.
- Wired tab switching through the existing button event handler.

## Checks Run

- `UV_CACHE_DIR=/tmp/uv-cache PYTHONPATH=src/voice-note uv run python -m compileall src/voice-note/voice_note/tui/app.py`
- `UV_CACHE_DIR=/tmp/uv-cache PYTHONPATH=src/voice-note uv run python -m unittest discover -s src/voice-note/tests`

## Notes

- The tabs are implemented with a lightweight show/hide approach rather than a dedicated Textual tab widget, because the installed Textual build does not expose tab widgets here.
- This keeps the code compatible with the current dependency set while giving the workspace the requested structure.
