# voice-note TUI Real Tabs Migration

## Summary

Replaced the custom show/hide tab shell with Textual's built-in `TabbedContent` and `TabPane` widgets.

## Changes

- Switched the main screen to a real `TabbedContent` container.
- Kept the four requested sections as tabs:
  - Notes
  - Session
  - Help
  - Settings
- Removed the fake tab button row and tab-panel visibility CSS.
- Wired tab activation to update the current tab state and refresh the settings runtime summary.
- Kept the existing session, notes, and action widgets inside the corresponding panes.

## Checks Run

- `UV_CACHE_DIR=/tmp/uv-cache PYTHONPATH=src/voice-note uv run python -m compileall src/voice-note/voice_note/tui/app.py`
- `UV_CACHE_DIR=/tmp/uv-cache PYTHONPATH=src/voice-note uv run python -m unittest discover -s src/voice-note/tests`
