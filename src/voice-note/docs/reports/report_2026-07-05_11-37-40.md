# voice-note Note Navigation With Arrow Keys

## Summary

Added note navigation support for the up/down arrow keys while keeping the
existing `j`/`k` vim-style navigation intact.

## Changes

- Added `down` and `up` bindings to map to the existing next/previous note
  actions.
- Kept note selection behavior clamped to the available transcript range.
- Kept the currently selected note visible through the existing render-and-scroll
  path.
- Added tests that verify both the bindings and the movement behavior.

## Checks Run

- `PYTHONPATH=src/voice-note uv run python -m unittest discover -s src/voice-note/tests`

## Notes

- The transcript list is already rendered oldest-to-newest, so navigation now
  moves naturally from the top note downward with either vim keys or arrows.
