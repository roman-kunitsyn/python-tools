# voice-note Note Selection and Clipboard Copy

## Summary

Added contiguous note range selection with shift-based vertical navigation and a
clipboard copy action that copies only note text.

## Changes

- Added shift-enabled note navigation bindings for `up`, `down`, `j`, and `k`.
- Added selection anchor/end tracking so a note range can be highlighted in the
  transcript pane.
- Added a copy action that joins selected note text without timestamps or other
  metadata.
- Added a small clipboard adapter that prefers macOS `pbcopy` and falls back to
  common desktop clipboard tools.
- Added tests for shift selection, plain-text copy behavior, and the clipboard
  adapter command selection.

## Checks Run

- `PYTHONPATH=src/voice-note uv run python -m unittest discover -s src/voice-note/tests`

## Notes

- The copy action is available from the keyboard through `y` and `ctrl+shift+c`.
- Range highlighting uses a lighter selected-card treatment for non-focused
  notes so the current note remains visually distinct.
