# voice-note Active Note Auto-Scroll

## Summary

Updated the transcript widget so the active note is scrolled into view whenever selection changes.

## Changes

- Converted the notes transcript to a `VerticalScroll`-backed custom widget.
- Kept each note as a card widget so the active note can be targeted directly.
- Added auto-scroll to the selected card after:
  - note navigation
  - note refresh
  - new note insertion
- Kept the selected note visually emphasized with the active panel styling.

## Checks Run

- `UV_CACHE_DIR=/tmp/uv-cache PYTHONPATH=src/voice-note uv run python -m compileall src/voice-note/voice_note/tui/app.py`
- `UV_CACHE_DIR=/tmp/uv-cache PYTHONPATH=src/voice-note uv run python -m unittest discover -s src/voice-note/tests`

## Notes

- The widget now owns the scroll position instead of relying on the terminal's default text wrapping.
- New notes should appear selected and be brought into view automatically.
