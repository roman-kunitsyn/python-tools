# voice-note TUI Layout and QR Compression Update

## Summary

Fixed the button groups to lay out horizontally and reduced the QR block size so the transcript panel can remain visible.

## Changes

- Changed the zoom controls to a horizontal row.
- Changed the note action buttons to a horizontal row.
- Reduced the QR card width and removed extra QR padding.
- Switched QR rendering to use a shorter payload based on the session folder name instead of the full path.
- Kept the transcript panel as the `1fr` region in the main vertical stack.

## Checks Run

- `UV_CACHE_DIR=/tmp/uv-cache PYTHONPATH=src/voice-note uv run python -m compileall src/voice-note/voice_note/tui/app.py`
- `UV_CACHE_DIR=/tmp/uv-cache PYTHONPATH=src/voice-note uv run python -m unittest discover -s src/voice-note/tests`

## Notes

- The QR is still generated in the terminal, so its physical size depends on the terminal font and available width.
- If you want, the next step is to wire the QR to a real telegram deep link payload so it becomes a true "join session" code instead of a session identifier.
