# voice-note Tab Navigation Cleanup

## Summary

Removed the custom tab-navigation shortcuts and event interception so the TUI
uses Textual's default tab behavior again.

## Changes

- Removed the custom `h`/`l` and arrow-key tab bindings.
- Removed the custom tab-cycle helper and `on_key()` interception.
- Kept the `Assistant` tab itself in place.
- Removed tests that depended on the custom tab-navigation implementation.

## Checks Run

- `PYTHONPATH=src/voice-note uv run python -m unittest discover -s src/voice-note/tests`

## Notes

- This cleanup was done because the custom navigation was producing unstable
  runtime behavior and was harder to reason about than the built-in Textual
  handling.
