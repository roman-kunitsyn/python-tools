# voice-note TUI Layout Compactness Update

## Summary

Reshaped the TUI so the session header stays compact and the transcript panel gets the remaining vertical space.

## Changes

- Kept the session chooser workflow intact.
- Reworked the main workspace into a vertical stack.
- Added compact session title, description, and folder path widgets.
- Renamed the session path widget so it behaves like a folder link.
- Kept the QR code in the top summary block with a fixed card width.
- Moved the transcript panel above the note details/actions strip so notes are visible first.
- Kept transcript rows ordered newest-first through the session store ordering.
