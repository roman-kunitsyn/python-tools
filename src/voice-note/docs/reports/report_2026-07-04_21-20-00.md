# voice-note Transcript Card Styling

## Summary

Restyled the transcript output into bordered Rich cards with a stronger selected-state treatment.

## Changes

- Rendered each note as a bordered card instead of plain text blocks.
- Highlighted the selected note with:
  - blue background
  - yellow text
  - stronger border color
  - extra padding to make it visually larger
- Kept the transcript scrollable inside the Notes tab.
- Preserved newest-first ordering and selection behavior.

## Checks Run

- `UV_CACHE_DIR=/tmp/uv-cache PYTHONPATH=src/voice-note uv run python -m compileall src/voice-note/voice_note/tui/app.py`
- `UV_CACHE_DIR=/tmp/uv-cache PYTHONPATH=src/voice-note uv run python -m unittest discover -s src/voice-note/tests`

## Notes

- Terminal apps can’t change the actual font size, so the selected note is emphasized with padding, bold styling, and a blue/yellow card treatment instead.
