# voice-note Transcript Widget Rewrite

## Summary

Replaced the transcript table with a custom scrollable note list that renders each note in full.

## Changes

- Removed the `DataTable`-based transcript widget.
- Added a custom `NoteListView` built on `ListView`.
- Added `NoteListItem` cards that show:
  - note timestamp
  - audio availability
  - full note text
- Kept notes ordered newest-first from the session store.
- Kept selection and keyboard navigation working through the list view.
- Reused `+` and `-` to change the selected note's zoom class.
- Removed the old table-specific cursor and padding logic.

## Checks Run

- `UV_CACHE_DIR=/tmp/uv-cache PYTHONPATH=src/voice-note uv run python -m compileall src/voice-note/voice_note/tui/app.py`
- `UV_CACHE_DIR=/tmp/uv-cache PYTHONPATH=src/voice-note uv run python -m unittest discover -s src/voice-note/tests`

## Notes

- Terminal UIs cannot change the real font size, so the selected note zoom is represented with layout padding/spacing.
- The new list is scrollable and shows the full text content of each note instead of collapsing long text into a table cell.
