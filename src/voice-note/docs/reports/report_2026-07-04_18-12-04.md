# voice-note Session Lifecycle Report

## Summary

Added the first slice of the new session-first TUI flow.

## Changes

- Added a session model with slug/title helpers and derived artifact paths.
- Added a session service for creating, loading, discovering, and renaming session folders.
- Updated default storage naming to use the session title slug plus timestamp.
- Added a startup modal for creating a new session or continuing an existing one.
- Changed the TUI to build the runtime service after the session is chosen.
- Changed the session link/open behavior so Enter opens the session folder instead of the transcript file.
- Added tests for session slugging, discovery, rename behavior, and the new folder-based open helpers.
