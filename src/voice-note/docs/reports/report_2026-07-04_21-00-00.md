# voice-note Transcript Widget Recovery

## Summary

Replaced the broken ListView-based transcript implementation with a custom scrollable text widget that renders complete note cards.

## Changes

- Removed the ListView note mounting path that was failing on repeated refreshes.
- Added `NoteTranscriptView`, a custom `Static` widget for transcript rendering.
- Rendered each note as a full card with:
  - note index
  - timestamp
  - audio marker
  - full note text
- Kept the notes scrollable via `VerticalScroll`.
- Kept the selected note highlighted in the rendered output.
- Kept `+` and `-` zoom controls by changing card spacing around the selected note.

## Checks Run

- `UV_CACHE_DIR=/tmp/uv-cache PYTHONPATH=src/voice-note uv run python -m compileall src/voice-note/voice_note/tui/app.py`
- `UV_CACHE_DIR=/tmp/uv-cache PYTHONPATH=src/voice-note uv run python -m unittest discover -s src/voice-note/tests`

## Notes

- This avoids async child-mounting problems in `ListView`.
- The widget now renders the full transcript text in order and remains stable across note refreshes.
