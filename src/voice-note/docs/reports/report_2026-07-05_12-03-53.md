# voice-note Tab Navigation With Arrows and Vim Keys

## Summary

Added keyboard tab navigation for the workspace tabs so users can move between
panels with both arrow keys and `h`/`l`.

## Changes

- Added `left` and `right` bindings for previous/next tab navigation.
- Added `h` and `l` bindings for the same tab actions.
- Added tab-cycle helpers so the main workspace walks through `Notes`,
  `Session`, `Help`, and `Settings` in a fixed order.
- Kept the existing direct tab actions intact.
- Made `_show_tab()` tolerant of unmounted state so tests can exercise the tab
  cycle logic without a live Textual UI.
- Added tests for binding coverage and tab-cycle behavior.

## Checks Run

- `PYTHONPATH=src/voice-note uv run python -m unittest discover -s src/voice-note/tests`

## Notes

- Tab navigation now mirrors the note navigation style: there is a primary
  action path plus multiple shortcut keys that all land on the same behavior.
