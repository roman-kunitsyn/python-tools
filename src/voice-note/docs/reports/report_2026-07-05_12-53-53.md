# voice-note Assistant Tab

## Summary

Added a dedicated `Assistant` tab to the TUI workspace and included it in the
workspace tab cycle.

## Changes

- Added a new `Assistant` `TabPane` to the main tabbed workspace.
- Added an `action_show_assistant_tab()` helper for direct navigation.
- Updated the tab order so the cycle now goes:
  `Notes -> Session -> Help -> Assistant -> Settings -> Notes`.
- Added a test that verifies the new tab appears in the cycle sequence.

## Checks Run

- `PYTHONPATH=src/voice-note uv run python -m unittest discover -s src/voice-note/tests`

## Notes

- The tab is intentionally a lightweight placeholder for now, matching the
  project’s existing incremental TUI approach.
