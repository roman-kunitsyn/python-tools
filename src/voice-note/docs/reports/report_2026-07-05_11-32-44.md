# voice-note Oldest-First Transcript Ordering

## Summary

Changed note ordering so session transcripts now render oldest to newest in both
the structured note store and the generated `transcribe.txt` file.

## Changes

- Updated `SessionNoteStore.load_notes()` to return notes in ascending
  `created_at` order.
- Updated note writes so new notes append at the end of the stored collection
  instead of being inserted at the front.
- Updated `replace_notes()` to preserve oldest-first ordering when rewriting
  the note store.
- Updated the TUI reload path so the active note still points at the most recent
  note after a new recording is added.
- Adjusted the existing unit test to assert oldest-first file and JSON output.

## Checks Run

- `PYTHONPATH=src/voice-note uv run python -m unittest discover -s src/voice-note/tests`

## Notes

- This slice keeps the visible transcript order and on-disk transcript order in
  sync, which prevents the TUI from showing a different sequence than the text
  artifact.
