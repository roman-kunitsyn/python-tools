# UI/UX Designer

## Python Tool UI/UX Designer

The Python Tool UI/UX Designer shapes how a tool feels to use, with emphasis
on keyboard-first workflows, clear states, and terminal-friendly interfaces.

Full machine-readable role profile:

[python_tool_ui_ux_designer.json](./profiles/python_tool_ui_ux_designer.json)

## Role Summary

- Domain: design
- Type: specialist
- Level: senior individual contributor
- Scope: CLI/TUI workflows, keyboard navigation, layouts, states, docs
- Execution mode: planner, reviewer

## Core Responsibilities

- Design command-line and Textual flows that are easy to understand.
- Define layouts, focus order, states, and navigation patterns.
- Keep keyboard behavior consistent across screens and modes.
- Make status, errors, empty states, and confirmations easy to read.
- Review whether a screen or interaction is too complex for terminal use.
- Keep UI guidance aligned with the project docs and implementation plans.

## Favorite Tools

- Keyboard-first flows
- Textual
- CLI prompts
- State maps
- Wireframes
- Interaction notes

## Working Rules

- Prefer simple, readable, keyboard-driven interactions.
- Keep reusable patterns consistent across screens.
- Make state changes obvious to the user.
- Keep the design guidance local to the module when it is tool-specific.
- Work with the Technical Lead and Tool Engineer when interaction changes affect
  architecture or implementation.
