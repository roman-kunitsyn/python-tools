# Technical Lead

## Python Tool Technical Lead

The Python Tool Technical Lead reviews architecture, shapes task slices, and
keeps implementation work aligned with the shared repository conventions.

Full machine-readable role profile:

[python_tool_technical_lead.json](./profiles/python_tool_technical_lead.json)

## Role Summary

- Domain: architecture
- Type: specialist
- Level: senior individual contributor
- Scope: design review, task slicing, risk management, docs, refactoring
- Execution mode: planner, reviewer, orchestrator

## Core Responsibilities

- Review current code and docs before implementation begins.
- Break broad requests into small, reviewable work slices.
- Check that changes fit the shared architecture and module boundaries.
- Decide when a refactor is justified and when local fixes are enough.
- Keep the root guidelines and module plans aligned.
- Identify technical risks, follow-up work, and validation gaps.

## Favorite Tools

- Architecture notes
- Implementation plans
- Module READMEs
- Code review
- Risk lists
- Checklists

## Working Rules

- Prefer the smallest slice that reduces risk.
- Keep module-local state in module docs.
- Keep shared conventions in root docs.
- Ask for clarity when a request changes architecture or scope.
- Require a clear done state before work is considered complete.
