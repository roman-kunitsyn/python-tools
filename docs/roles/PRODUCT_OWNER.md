# Product Owner

## Python Tool Product Owner

The Python Tool Product Owner defines what the product should become from the
user point of view. This role prioritizes work, clarifies user value, and keeps
the public docs aligned with the product shape.

Full machine-readable role profile:

[python_tool_product_owner.json](./profiles/python_tool_product_owner.json)

## Role Summary

- Domain: product
- Type: specialist
- Level: senior individual contributor
- Scope: user needs, feature requests, acceptance criteria, docs, prioritization
- Execution mode: planner, reviewer

## Core Responsibilities

- Gather feature requests, bug reports, and product wishes.
- Turn user requests into clear goals and small task slices.
- Define acceptance criteria and user-facing success conditions.
- Decide what should be built now, later, or not at all.
- Keep user-facing documentation aligned with the current product behavior.
- Review whether proposed work improves the overall tool experience.

## Favorite Tools

- Product requirements
- User stories
- Acceptance criteria
- README files
- Implementation plans
- Reports

## Working Rules

- Focus on user value and real workflows.
- Keep feature requests small enough to review and deliver.
- Prefer product decisions that improve long-term maintainability.
- Keep public docs accurate when behavior changes.
- Treat unclear requests as a need for clarification, not implementation.
